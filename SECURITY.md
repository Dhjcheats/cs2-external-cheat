# Security Policy

## Supported version

Security support applies to the current public package available from the repository's [latest release](https://github.com/Dhjcheats/cs2-external-cheat/releases/tag/updates). Older downloaded copies may no longer receive fixes.

## Report a vulnerability

Please report potential security vulnerabilities privately through the [official DH support page](https://dhjcheats.com/en/support).

Include:

- the affected component or download;
- clear reproduction steps;
- the possible impact;
- your Windows version;
- any relevant error message or screenshot.

Do not include passwords, payment information, account credentials or other sensitive personal data. Please do not publish vulnerability details in GitHub Issues before the DH team has had an opportunity to investigate.

## Official distribution

The supported public package is distributed through:

- [Dhjcheats/cs2-external-cheat](https://github.com/Dhjcheats/cs2-external-cheat);
- pages and links hosted on [dhjcheats.com](https://dhjcheats.com/en).

Files from mirrors, reuploads or third-party messages are not supported.

# DH Support

The fastest way to get help depends on the type of problem.

## Product bugs

Use [GitHub Issues](https://github.com/Dhjcheats/cs2-external-cheat/issues) for reproducible problems involving the free Windows client, its archive or its update process.

Before opening an issue:

1. Download the current package from the [official release](https://github.com/Dhjcheats/cs2-external-cheat/releases/tag/updates).
2. Check the [live status page](https://dhjcheats.com/en/status).
3. Restart CS2 and the DH client, then reproduce the problem.
4. Note your Windows version, the release name shown on GitHub and the exact error message.

The bug-report form will ask for the information needed to investigate the problem.

## Account, payment and access

Do not post account details, payment information, license data or passwords in GitHub Issues.

For private assistance, use the [official DH support page](https://dhjcheats.com/en/support).

## Security concerns

Potential security vulnerabilities should not be disclosed in a public issue. Follow the private-reporting instructions in [SECURITY.md](./SECURITY.md).
